**Goal:** Add reactive + synchronous service-acquired accessor faces to `appbase-cloud-aws-s3`, on the shared Appbase accessor spine, over AWS SDK v2's S3 clients — reactive via `Mono.fromFuture` over `S3AsyncClient` (netty-nio, non-blocking), sync over `S3Client` (apache-client, truly blocking).

**Architecture:** ES-shaped existing-async surface (the module already has a bespoke `ObjectStoreAccessor` with sync + `CompletableFuture` faces; the twin adds the reactive face + brings both onto the shared spine), Cassandra-shaped acquisition (getters on `S3ClientsService extends AppbaseClientService<S3Clients, ClusterIdValue>`, borrow the pooled integration service, **keyed free**). Sync ≠ non-blocking: sync accessor → `S3Client`, reactive → `S3AsyncClient`.

**Tech Stack:** Java 25, Reactor 3.6.8, AWS SDK v2 S3 (`S3Client`/`S3AsyncClient`, `software.amazon.awssdk.core.exception.SdkException`), Micrometer (spine `Timer`), Guice, Maven, JUnit 5 + Mockito + `reactor-test`.

**Reference twins:** Cassandra (`ReactiveCassandraAccessor` `Mono.usingWhen(borrow, …, finalizeOperation)`; `DefaultCassandraClientService` getters/config; keyed-free acquisition). Elasticsearch (existing-async-surface twin). Jasync (`JasyncAccessorException.map` unwrap). All in the working tree (epic).

**Design:** `docs/specs/2026-07-07-P027-R2a-reactive-s3-design.md`.

## Established facts (verified)

- `S3ClientsService extends AppbaseClientService<S3Clients, ClusterIdValue>`; `S3Clients` (`getS3Client()` sync, `getS3AsyncClient()` async). `DefaultS3ClientsService` mirror-able to `DefaultCassandraClientService` for acquisition; `getConfiguration()` returns the concrete config.
- `S3ClientsServiceConfiguration extends AppbaseClientServiceConfiguration {}` is EMPTY — Task 1 adds the reactive getter.
- Existing `ObjectStoreAccessor`/`AbstractObjectStoreAccessor` ops (mirror these): sync `readObjectAsInputStream|readObjectAsFile|readObjectAsBytes`/`writeObject(Path|byte[])`/`deleteObject`/`existsBaseDirectory`/`deleteBaseDirectory` (throw `IOException`); async `asyncReadObjectAs…`/`asyncWriteObject(…)`/`asyncDeleteObject`/`asyncCreateBaseDirectory`/`asyncExistsBaseDirectory`/`asyncDeleteBaseDirectory` (→ `CompletableFuture`). Sync uses `getS3Client()`, async uses `getS3AsyncClient()`.
- AWS SDK exceptions all extend `software.amazon.awssdk.core.exception.SdkException` (incl. `S3Exception`, `NoSuchKeyException`); S3 SDK errors are **unchecked** (extend `RuntimeException`) — so the sync generic `command` can use `java.util.function.Function<S3Client,T>` (NO throwing interface needed; confirm at build).
- `AbstractReactiveAccessor(AppbaseCore, ReactorService, ReactiveOperationConfiguration)` + `mono`/`flux`; `AbstractAppbaseAccessor(AppbaseCore, metricsEnabled, traceEnabled, exceptionStoreEnabled)` + `execute`; both read flags from `ReactiveOperationConfiguration`. `DefaultReactiveOperationConfiguration` in `…client.core.reactive`.

**Interfaces:**
- `S3AccessorException extends AppbaseClientException` — ctors `(Throwable)`/`(String,Throwable)`; static `map(Throwable, Function<Throwable,Throwable> fallback)` unwrapping `CompletionException`/`ExecutionException` → cause; `cause instanceof SdkException` → `new S3AccessorException(cause)`; else fallback (mirror `JasyncAccessorException.map`, substituting `software.amazon.awssdk.core.exception.SdkException`).
- `ReactiveS3Accessor extends AbstractReactiveAccessor` — ctor `(AppbaseCore, ReactorService, ReactiveOperationConfiguration, Supplier<AppbaseClientIntegrationService<S3Clients, ClusterIdValue>> borrow)`. A private helper:
  ```java
  private <T> Mono<T> call(String op, Function<S3AsyncClient, CompletableFuture<T>> fn) {
      return mono(op, () -> Mono.usingWhen(
          Mono.fromSupplier(borrow),
          svc -> Mono.fromFuture(() -> fn.apply(svc.getClient().getS3AsyncClient())),
          svc -> Mono.fromRunnable(svc::finalizeOperation)));
  }
  ```
  Ops mirroring the ObjectStore vocabulary over `S3AsyncClient` (each delegates to `call`): `Mono<byte[]> readObjectAsBytes(op, objectId)` (via `getObject(req, AsyncResponseTransformer.toBytes())` → map `ResponseBytes::asByteArray`), `Mono<Path> readObjectAsFile(op, objectId, destPath)`, `Mono<String> writeObject(op, byte[], objectId)`, `Mono<String> writeObject(op, Path, objectId)`, `Mono<Boolean> deleteObject(op, objectId)`, `Mono<Boolean> existsBaseDirectory(op)`, `Mono<String> createBaseDirectory(op)`, `Mono<Boolean> deleteBaseDirectory(op)`; generic `<T> Mono<T> command(op, Function<S3AsyncClient, CompletableFuture<T>> fn)` = `call(op, fn)`. `mapError` = `S3AccessorException.map(t, super::mapError)`; `isNotable` = `true`. **Javadoc: reactive face uses `S3AsyncClient` (netty-nio, non-blocking) → `Mono.fromFuture`; `usingWhen` returns the borrow on complete/error/cancel.**
