# Appbase developer MCP lookup core

This package is the lookup core and pinned stdio MCP transport for internal work item 2687. It intentionally has no
third-party dependency: the transport registers the three methods on `LookupHandlers` without
coupling catalog validation to a particular Python MCP SDK.

The API catalog is generated by `scripts/generate-mcp-api-surface.sh`. The generator uses the JDK
compiler tree API over Git-tracked `src/main/java` files; it does not use a hand-maintained symbol
list. `scripts/verify-mcp-api-surface.sh` independently checks every generated type and method
against the full reactor's compiled classes with `javap`. The serving package never repairs an
artifact and refuses to start from absent, malformed, duplicate, or stale metadata. The generated
JSON contract is:

```json
{
  "schema_version": 1,
  "source_revision": "<lowercase 40-character Git commit SHA>",
  "symbols": [
    {
      "id": "<stable unique symbol identifier>",
      "qualified_name": "<fully qualified Java type>",
      "kind": "<symbol kind>",
      "signature": "<source-derived declaration>",
      "source_path": "<repository-relative Java source path>"
    }
  ]
}
```

Callers should pass the checked-out commit as `expected_revision`; a mismatch fails closed rather
than serving a plausible but stale API.

Run the stdio server through the lifecycle wrapper (the command an MCP host should spawn):

```bash
scripts/start-appbase-developer-mcp.sh
```

The wrapper regenerates the API artifact for the exact checkout, records the child PID under
`target/appbase-mcp/server.pid`, reserves stdout for MCP frames, and removes the PID file when the
client closes stdin. An operator can stop a wedged host-owned process with
`scripts/stop-appbase-developer-mcp.sh`; the stop script refuses to signal a PID whose command line is
not this repository's MCP server.

The process speaks newline-delimited JSON-RPC exclusively on stdout and pins the MCP `2025-06-18`
handshake. It exposes `lookup_api`, `lookup_convention`, and `list_conventions` through `tools/list`
and `tools/call`. See `docs/developer-mcp.md` for the normative boundary and operator guide.

Generate and verify after a full reactor compile:

```bash
bash scripts/generate-mcp-api-surface.sh /tmp/appbase-api-surface.json
bash scripts/verify-mcp-api-surface.sh /tmp/appbase-api-surface.json
```

`conventions.json` is a small curated seed derived from current repository behavior. Its private
validation descriptors bind every entry to executable Java or Maven semantics, and the drift test
rejects a seed whose evidence no longer describes the tree.

## Acceptance status

The Spec and Plan are review candidates and must receive independent review before internal work item 2687 completes.
The CI compile tier performs the same generate-and-verify sequence. Changes to the generator or
oracle force a full reactor build so that this independent compiled-artifact check cannot produce a
partial-build false green.
The transport's fixture tests do not replace that compiled-artifact oracle.
